# 陳年卷宗 (`pg-casefile`)

一夜份的點選推理冒險。海線舊站 1987 年的蒸汽管事故被寫成「意外」，替死鬼背了三十年；
今晚舊站要拆，你有一夜把卷宗翻過來。

類型：**點選冒險（推理）** · 系列：懷舊

## 玩法

- **點現場的光點**＝搜查熱點（5 個場景、共 19 個熱點）。
- **點證物**＝選取；拿著它**點熱點**＝使用（開鎖、拆蓋、細看）。
- **連點兩件證物**＝嘗試組合（顯影底片、復原焦黑班表、拼回撕碎的信、對照打卡與日誌）。
- **保險箱**用頁內數字鍵盤輸入四位密碼（號碼藏在站長室裡）。
- **指認**：選一名嫌疑人，並把「動機／機會／物證」三張推理卡擺上桌。
  指錯或證據鏈不成立會被檢察官退件並給出針對性反駁；**退件三次，卷宗封存**。

進度（含最少行動數紀錄）走宿主的 `/api/kv`，不使用裸 localStorage。

## 開發

純 HTML／CSS／JavaScript，無 build。本機開 `index.html`，或經 Playgrounds／go 安裝。

```bash
npx vitest run    # 45 個規則測試
```

原始碼分工：`content.js`（案件資料）、`game.js`（純規則）、`art.js`（程式繪製的 noir 場景）、
`app.js`（介面）、`audio.js`（實際播放 `assets/audio/*.ogg`）、`persist.js`（`/api/kv`）。
